# AGENTS.md

## Project overview
This repo contains Python scripts for EVE Application.

## Structure
- `IDM2040_demo/` — main scripts

## Conventions
- Use Python 3.11+
- Follow PEP8 style
- All functions must have docstrings
- Run `pytest` before committing

## Commands
- Run tests: `pytest`
- Lint: `flake8 src/`
- Install deps: `pip install -r requirements.txt`
